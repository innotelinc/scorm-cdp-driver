scorm-cdp-driver — Advance a SCORM player through a Chrome tab you already control.

A zero-dependency Node driver for a SCORM e-learning player running in a Chrome tab. It drives the player over the Chrome DevTools Protocol, presses Next only when a slide's narration has finished, clears the known progress gates, checks each answer guess against the player's own feedback, and stops at the attestation instead of answering it.

View on GitHub Quick start 
chrome --remote-debugging-port=9222

Synthetic clicks are ignored by the player.

Real CDP input events at real coordinates, translated through nested iframes.

Next is gated on the narration timeline.

The driver waits for the timeline to finish rather than clicking early.

Policy links and knowledge checks block progress.

The known gates are cleared, and the attestation is deliberately left to the learner.
